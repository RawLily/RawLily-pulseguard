                      3. VERCEL DEPLOYMENT
================================================================================

STEP 1: Connect GitHub Repository
──────────────────────────────────

1. Go to https://vercel.com/dashboard
2. Click "Add New Project"
3. Select "Import from Git"
4. Search for "RawLily-pulseguard"
5. Click "Import"
6. Vercel auto-detects Next.js framework ✓

STEP 2: Configure Project Settings
────────────────────────────────────

1. Enter Project Name: "pulseguard"
2. Root Directory: ./ (default)
3. Framework Preset: Next.js (auto-detected)
4. Build Command: npm run build
5. Output Directory: .next

STEP 3: Add Environment Variables
──────────────────────────────────

Add these variables in Vercel project settings:

✓ AUTH0_SECRET
✓ AUTH0_BASE_URL
✓ AUTH0_ISSUER_BASE_URL
✓ AUTH0_CLIENT_ID
✓ AUTH0_CLIENT_SECRET
✓ DATABASE_URL
✓ NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
✓ STRIPE_SECRET_KEY
✓ STRIPE_WEBHOOK_SECRET
✓ STRIPE_PRICE_ID_MONTHLY
✓ STRIPE_PRICE_ID_YEARLY
✓ RESEND_API_KEY
✓ NEXT_PUBLIC_SENTRY_DSN
✓ NEXT_PUBLIC_APP_URL
✓ NODE_ENV (set to "production")
✓ ENCRYPTION_KEY
✓ JWT_SECRET

STEP 4: Deploy
───────────────

1. Click "Deploy"
2. Wait 2-3 minutes for build to complete
3. Once complete, visit your Vercel URL: https://pulseguard-[random].vercel.app
4. Verify homepage loads with:
   ✓ Heartbeat SVG logo
   ✓ "Pulse" (white) + "Guard" (green) text
   ✓ Three green security badges
   ✓ Free / Monthly / Yearly pricing cards

STEP 5: Configure Custom Domain
────────────────────────────────

1. In Vercel: Settings → Domains
2. Add "pulseguardhq.xyz"
3. Follow DNS configuration instructions
4. Update Auth0 callback URLs to production domain
5. Wait 24-48 hours for DNS propagation

================================================================================
                         7. TROUBLESHOOTING
================================================================================

DEPLOYMENT FAILED
──────────────────

Error: "Build failed"
→ Check Vercel build logs for specific error
→ Verify all environment variables are set
→ Ensure Node.js version is 24.x
→ Clear build cache: Settings → "Rebuild cache" → "Clear"

Error: "Cannot find module '@auth0/nextjs-auth0'"
→ Run: npm install
→ Check package.json dependencies
→ Ensure all dependencies are listed

HOMEPAGE NOT LOADING
─────────────────────

Problem: Logo not rendering
→ Check /public folder exists and has assets
→ Verify SVG syntax in app/page.tsx
→ Check browser console for errors

Problem: Styling broken (colors off)
→ Verify tailwind.config.js is correct
→ Clear browser cache: Cmd+Shift+Delete
→ Check Tailwind CSS in globals.css

AUTH0 REDIRECT FAILS
─────────────────────

Error: "Invalid callback_url"
→ Add to Auth0 Dashboard → Settings → Callback URLs:
   https://pulseguardhq.xyz/api/auth/callback

Error: "Unauthorized" on login
→ Verify AUTH0_CLIENT_ID and AUTH0_CLIENT_SECRET
→ Check AUTH0_BASE_URL matches domain exactly
→ Verify application type is "Single Page Application"

STRIPE CHECKOUT NOT WORKING
─────────────────────────────

Error: "Price not found"
→ Verify STRIPE_PRICE_ID_MONTHLY and STRIPE_PRICE_ID_YEARLY exist
→ Ensure prices are in USD
→ Check price IDs start with "price_"

Error: "Invalid publishable key"
→ Use pk_live_ in production (not pk_test_)
→ Ensure NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY is set in Vercel
→ Redeploy after updating variables

WEBHOOK NOT TRIGGERING
───────────────────────

Problem: Stripe webhook endpoint not receiving events
→ Verify endpoint URL: https://pulseguardhq.xyz/api/webhooks/stripe
→ Check STRIPE_WEBHOOK_SECRET is correct in Vercel
→ Test webhook in Stripe dashboard
→ Check Vercel logs for incoming requests

DATABASE CONNECTION FAILS
──────────────────────────

Error: "ECONNREFUSED"
→ Verify DATABASE_URL is correct
→ Ensure Neon database is active
→ Check IP whitelist in Neon (allow all for testing)
→ Test connection locally first
